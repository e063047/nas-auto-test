代表作品

NAS 產品測試自動化專案範例

這是我實際使用 Claude Code 開發 NAS 自動化測試的過程，呈現從規劃到執行的完整思路，以及面對挑戰時的做法與成效。

背景與動機

  • 產品每次 FW 升級都得將測試項目重新人工驗證一輪，耗時且容易漏測
  • 設計一套讓測試人員不必懂程式、就能對 NAS 跑完整測試的自動化測試程式

我的角色

  • 以測試工程師的專業，負責規劃測試策略
  • 監督 AI 產出的準確性與測試涵蓋率是否足夠

AI 執行策略

  • 先產出 Test Plan，經我審核才開發
  • 不確定處先確認，避免 AI 自行推測
  • 每個模組都在實機驗證

具體成果

  • 包含 BAT 與 Basic function 共 59 個測試項目
  • 暫停與恢復測試功能，靈活應變各種測試情況
  • 一鍵輸出 HTML/PDF/XML report
  • 預估減少 80% 測試時間
目標讓測試人員免寫程式，一鍵完成 FW 升級後的完整驗證

技術工具與方法

程式語言與技術
  • Python（後端與測試案例開發）
  • FastAPI（儀表板 API 與即時進度推播）
  • Playwright（自動操作網頁並截圖）
  • Paramiko（SSH／SFTP 連線驗證）
方法
  • 階段式流程＋人工審核
  • BAT/Basic function 分層測試
報告與視覺化
  • 即時儀表板
  • 自動產生 HTML／PDF／JUnit XML／JSON 測試報告
