Execution State Machine

開始、暫停、恢復、中斷

暫停不會打斷正在跑的測試。當前 Test Case 完整結束後，引擎才停在下一支之前，NAS 不會停在寫到一半的狀態。

Case N
按下暫停 ▸
Case N+1

Quick Start

四步驟完成一次驗證

STEP 1NAS ▾ 192.168.x.x

選擇 NAS

從下拉選單選取自動搜尋到的 NAS，或手動輸入 IP，再填入帳號密碼。

STEP 2☑ BAT　☑ SMB　☐ FW

勾選測試項目

以樹狀選擇器選 BAT、FULL，或只挑單一 Test Case。

STEP 3▶ 開始　❚❚ 暫停

按下開始

右側 Log 即時串流，隨時可暫停、恢復或中斷。

STEP 4report_*.html / .pdf / .xml

下載報告

含高階摘要與詳細 Log，附 JSON 與 JUnit XML 原始資料。

Web-First

一般測試人員用瀏覽器操作；同區網其他電腦可直接連線。

多協定驗證

FTP、SSH/SFTP、SMB、NFS 全數以 MD5 確認檔案完整。

CLI 與 CI/CD

Headless 執行、單一腳本除錯，可接上 CI/CD Pipeline。

可擴充架構

裝置抽象層隔離機型差異，同系列產品可共用測試。
